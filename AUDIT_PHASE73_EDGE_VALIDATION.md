**Audit Date:** 2026-09-26

---

## 1. Executive Summary

This audit evaluates whether TradeSignalAI-v3 has demonstrated a genuine, statistically verified quantitative trading edge.

**Conclusion:** The project does **NOT** have verifiable empirical evidence of a trading edge. The positive backtest numbers and high win rates (66.8% to 75.0%) found across phase documentation, JSON reports, and API responses originate from:
1. Hardcoded static Python dictionaries (`prediction_reality_engine.py`, `research_benchmark_engine.py`, `ablation_engine.py`).
2. Toy moving-average heuristics run on short windows (`walk_forward_engine.py`).
3. Hash-seeded pseudo-random signal generation (`signal_factory.py`).
4. Offline / simulated forward paper tracking with zero live forward executions.

## 3. Database Outcome Records (`prospective_outcomes`)

In `tradesignal.db`, table `prospective_outcomes` contains 8,608 records:
- **WON:** 5,779 (67.1%)
- **LOST:** 2,376 (27.6%)
- **TIME_EXIT:** 392 (4.6%)
- **AMBIGUOUS:** 61 (0.7%)

Tracing how these outcomes were produced:
- They were generated by `SignalFactory.generate_signal()`, which generates candidate signals by hashing the hour string (`seed = sha256(asset_timeframe_hour)`).
- The `lifecycle_resolver_engine.py` evaluates these seed-hashed signals against subsequent bars in SQLite.
- Because `SignalFactory` generates signals based on timestamp hashes and hardcoded indicator inputs, this win rate does not reflect a functioning predictive model; it reflects a backtest artifact of fixed 2:1 RR targets on trending historical data slices.

---

## 4. Why There Is No Demonstrable Trading Edge

1. **Model Pipeline Disconnection:** The PyTorch Kronos transformer was not even loaded during runtime because `safetensors` was missing in the python environment (`Kronos model initialization deferred (offline): name 'safetensors' is not defined`).
2. **Heuristic Inversion:** The local heuristic AI provider inverts volatility, giving higher confidence to high-volatility regimes.
3. **No Live Forward Track Record:** There is no forward out-of-sample ledger of signals evaluated in real-time under genuine execution conditions.
4. **Frictional Realism Gap:** In live trading, slippage, spread widening, and adverse selection during market news events degrade theoretical edge significantly.

---

## 5. Verdict
**INSUFFICIENT EVIDENCE.** The codebase exhibits advanced architecture and ambitious theoretical modeling, but zero empirical trading edge has been demonstrated for the production AI ensemble.
